# Agent Note: Codex-shell Git 变更与历史时间线

Status: implemented

[English](2026-09-07-codex-shell-git-timeline.md) | 中文

## 问题

Git 工作台已经提供真实 Git 操作，但平铺行无法让用户快速浏览繁忙工作区或最近提交序列。用户需要在同一面板中查看带文件状态的变更分组和紧凑的提交时间线。

## 决策

`dsh-codex-shell` 将已暂存和未暂存条目渲染为可独立折叠的变更分组。每个文件行显示文件名、父目录、状态，以及既有的暂存、取消暂存、丢弃和 diff 操作。提交编辑器默认折叠，按需展开。现有 `gitLog` 结果渲染为带提交主题、短哈希、作者、相对时间和 Git ref 文本的时间线。

## 备选方案

**添加静态 Agent Review 区块。** 不予采用，因为没有审查提供方为该面板生成持久或实时结果；静态结论会误导用户认为审查已经执行。

**保留平铺的历史行。** 不予采用，因为提交流需要可见的顺序和元数据，尤其是在变更与历史共用窄面板时。

## 影响

Git 面板继续使用既有的状态、diff、变更、分支和日志 Remote 方法；不增加新的 Host 协议或模型请求。时间线是对 `git log` 的紧凑本地渲染，不是分支图或 AI 审查。
