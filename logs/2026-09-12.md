# 2026-09-12 修改日志

## 修复桌面壳启动失败：shell 服务被两个 provider 重复注册

- 现象：双击根目录 `DeepSeek Harness.exe` 弹出 `dsh web exited (exit code 1) before printing dsh web: http...`，正文为 `service "shell" has been registered at <SandboxBashExecutor>`；端口无监听。
- 复现：按 `dsh.cmd` 的方式直接运行 `node --import tsx/esm apps/cli/src/bin.ts web --no-open`，得到同样的报错与退出码 1。报错链为 `pwsh-sandbox → SandboxPwshExecutor → PwshLocalExecutor → ShellExecutor` 注册 `shell` 时撞上已由 `SandboxBashExecutor` 注册的同名服务。
- 根因：`shell` 能力边界只允许**恰好一个** provider（`packages/shell/shell/src/index.ts` 的类文档写明「win32 层用 pwsh 行替换 POSIX 行，同时挂载会在重复服务注册上 fail loud」）。`packages/bundle/base/cordis.patch.yml` 用 `!!js` 按平台对称门控四行——`bash-sandbox`/`tool-bash` 在 win32 上禁用，`pwsh-sandbox`/`tool-pwsh` 在非 win32 上禁用。而本机 profile 的补丁层（由 `dsh-plugin-manager` 写入，优先级高于 bundle）对 `bash-sandbox`、`tool-bash`、`tool-pwsh` 各落下一条显式 `disabled: false`，把平台门控覆盖成「始终启用」，于是 Windows 上两个 provider 同时注册 `shell`，插件树加载失败、`dsh web` 立即退出。
- 处置：按该补丁层自带的说明「移除该行即把控制权交回上层配置」，删除这三条 manager 覆盖行（`bash-sandbox`/`tool-bash` 在 Windows 上必须保持禁用；`tool-pwsh` 一并交回，避免在非 Windows 上被钉死为启用）。未改动 bundle 与任何源码。
- 验证：同一命令重跑，输出就绪地址 `dsh web: http://127.0.0.1:3080/?token=...`，不再出现服务冲突；验证后已停止该实例，3080 已释放、无残留进程。
- 备注：该故障此前被 `dsh-browser-agent` 缺产物的问题遮蔽——插件树在更早的条目上先失败，修好前一层后才暴露出来。
- 已确认：不改动 `dsh-plugin-manager` 的行为；平台门控条目由使用者在管理界面自行避免开启。

## community 部署链路加固：主机自检与 profile 自愈

- 背景：在一台全新的 Windows on ARM64 主机上首次部署时接连受阻——profile 的 `file:` 依赖指向另一台机器的绝对路径；固定版本依赖已被作者从公共注册表下架；`github:` 依赖在访问不了 github.com 的网络中安装失败；原生依赖缺少 ARM64 二进制。这些都到启动阶段才以框架内部术语报出，定位成本高。
- 处置：`community/` 增加主机自检脚本 doctor.mjs（只读、逐项给出修复命令、有失败项时退出码非零）；新增 preflight.mjs 集中存放运行时版本要求、按平台划分的组合包限制与可达性探测；新增 profile.mjs 负责 manifest 的物化与修复。seed.mjs 改为自愈式：profile 已存在时只修复漂移的 tarball 路径与本机装不上的组合包，模板之外由使用者添加的组合包保持不变；首次播种时跳过注册表已不再提供、网络不可达或架构不支持的组合包并打印原因，不再写出必然安装失败的 profile。
- 验证：本机用临时 `DSH_HOME` 走通首次播种、重复播种静默无操作、人为制造路径漂移后自动修复、doctor 全项通过且退出码 0；ARM64 分支以模块级调用验证，仅摘除不兼容组合包且保留使用者自建条目。
- 备注：可达性探测以 HTTPS 请求为主、TCP 连通为辅。本机把 github.com 解析到本地代理，Node 自带 CA 库验签失败而 git 走系统证书库正常，单用 HTTPS 会把可达误判为不可达并误删组合包。
- 影响范围：仅 `community/` 下的部署脚本与文档，未改动 harness 源码与 profile 模板；英文与中文 README 同步更新并重录配对哈希。
