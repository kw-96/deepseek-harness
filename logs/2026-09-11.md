# 2026-09-11 修改日志

## 修复 DeepSeek 请求扩展准备失败（REQUEST_EXTENSION）

- 现象：Web 会话发送任意消息即报「DeepSeek request extension preparation failed」，整轮 DeepSeek 请求被中断。
- 根因：web profile 补丁层插入了主进程插件 @deepseek-ai/dsh-session-import-codex，但该包仅作为若干前端包的 devDependency 存在，未进入 dsh 安装的运行时依赖闭包。开发态由 tsx 的 tsconfig 路径映射兜底完成加载，Loader 条目因此激活；而默认启用的请求扩展包清单插件用 Node 原生解析（createRequire.resolve.paths）逐个校验活动条目所属包，解析不到该包便抛错，导致整轮请求失败。同时 $DSH_HOME/profiles/node_modules 下遗留了指向已消失目标的同名悬空链接。
- 处置：把 @deepseek-ai/dsh-session-import-codex 纳入 apps/cli 的运行时依赖（与同样由 profile 补丁行引用的 dsh-terminal、dsh-terminal-bash 保持一致），执行 pnpm install 生成安装闭包链接；重启 dsh web 后，profile 模块回退目录下的同名链接被自动修复为有效目标。
- 验证：profile 组合中的 162 个裸插件包已全部可被 Node 原生解析（修复前为 161/162）；dsh web 正常启动并输出访问地址。
- 备注：源码与依赖改动需重启 dsh web 后生效。
