## 处理 web e2e 遗留失败

- 现象：`test:web` 在 Windows 本机有一批失败，表现为 unknown tool bash、终端默认超时断言不符、打包 worker 启动超时；另有先前 Windows refresh 重录的会话夹具含本机临时路径，导致重放比较失败。
- 概述：bash 依赖的 web 用例按平台拆分跳过（preset 在 Windows 用 pwsh 取代 bash），plugin-config 默认超时按平台取值，回退被污染的夹具重录提交并补测试类 Agent Note。
- 验证：修改后的 8 个相关套件重放通过（1 个通过、7 个按平台跳过）；Agent Note 格式与翻译配对门禁通过。preview-boot 的 Windows 启动超时为环境计时问题，保持 Linux CI 预算不变。
