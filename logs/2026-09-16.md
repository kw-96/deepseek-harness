# 2026-09-16 开发日志

## 安装 dsh-remote-mobile@1.7.0（用户要求）

- 背景：用户要从局域网/手机远程使用 DSH，选定 `dsh-remote-mobile`（局域网 + Tailscale 双通道、扫码配对、移动端样式适配）。
- 处置：在 profile 目录用自带 pnpm 装 `dsh-remote-mobile@1.7.0`，并把它追加进 `dsh.profile.bundles`；装前存快照 `20260916-122027-da82`。
- 核对：插件的客户端产物只 require `react` 与 `react/jsx-runtime`（`dsh.client.inject` 里那个 `@deepseek-ai/dsh-client-runtime` 只是旧包名的信息性边，不参与加载，因此与当前 0.1.6 宿主兼容）；`--dump-config` 组合成功且含 `id: remote-mobile`、bundle 15 个；`verify-profile` 组合自检通过。
- 前置条件核对：README 要求 webserver 行 `host: 0.0.0.0`，本机 profile 早已如此，且当前宿主 schema 直接接受该值，故未改动；README 里那条 `inject: [webStartup]` 是旧宿主写法——本仓已无此服务，照抄会让 webserver 行永久 PENDING，故未采纳。
- 使用方式：重启后在浏览器进入 设置 → 远程与移动端，用手机相机或微信扫码接入；默认 6 位配对码 5 分钟有效、一次性使用，可另设长期访问密码，或对 Tailscale/局域网单独开启免密直连。
- 影响范围：本机 web profile（依赖、bundles、node_modules）；需重启 `dsh web` 生效。
