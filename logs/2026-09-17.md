## 移除自研浏览器面板并还原原生浏览器操作（用户决定）

- 背景：用户评估后认为该插件价值有限——Web 模式受图像流上限约束，桌面壳内的原生视图本质上也是壳提供的能力，决定不再维护。
- 处置：删除插件源码与社区目录登记；从 web profile 的 bundle 列表移除并摘除三个相关链接；把 browser-use 由 attach 改回原生 launch；回滚桌面壳为此新增的 unstable 特性、原生模块与命令注册，并重建可执行文件。
- 验证：组合自检 exit 0（740 行），无 browser-panel 残留，browser-use 显示 mode: launch，无解析错误。
- 影响范围：`community/plugins/packages`（移除插件）、`packages/experimental/web-desktop/src-tauri`（回滚壳改动）、本机 web profile（bundle 列表与链接）；需重启生效。
- 追加修复：还原为 launch 后浏览器工具立即报「chrome-for-testing is not installed」——本机已装的 Playwright 浏览器是 chromium-1228/1234，与当前 playwright-mcp 要求的 1243 不匹配。已用官方配置项 `executablePath` 指向本机 Chrome 153，免去下载；组合自检通过（exit 0、741 行、无错误）。

## 修复桌面壳里对话链接无法用系统浏览器打开（用户报告）

- 背景：用户反馈在桌面壳中点击对话里的链接从不跳转系统默认浏览器。该功能 9-11 就已做原生出口与前端拦截，但一直没生效。
- 定位：前端 `installExternalLinkHandler` 只有定义和测试，**生产代码里没有任何调用点**——接线遗漏，点击从未被接管。
- 处置：在 ui-layout 的客户端 apply 中按托盘同样的方式用 effect 安装该拦截器；重新构建该包并打包产物。
- 验证：该包测试通过（exit 0）；bundle 产物含该调用；装进 profile 后产物内含接线标记 `desktop external links`。
- 影响范围：`packages/client/ui-layout`（源码与 dist 产物）；需重启生效。
