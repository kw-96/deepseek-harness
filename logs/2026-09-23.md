# 2026-09-23

## dsh.taqu.team 返回 502 的排查与修复（桌面端监听地址）

- 现象：带 Basic Auth 访问 `https://dsh.taqu.team/` 返回 502；无凭据仍为 401，说明认证层正常、问题在上游。
- 定位：该域名的 nginx 反代在 09-20 已改指本机 `100.123.104.22:19387`（桌面端），而桌面端默认只绑回环 `127.0.0.1`，Tailscale 网卡上无监听，nginx 连上游被立即拒绝，于是返回 502。
- 排除项：Tailscale 链路正常（ICMP 与 tailscale ping 均为约 50 毫秒直连）；本机防火墙三个 profile 全部关闭；nginx 配置语法、443/8444 监听与 Basic Auth 均正常；nginx 日志级别为 crit，上游连接失败不落盘，因此日志中查不到 502 痕迹。
- 处置：在桌面端 profile 的 patch 层把 webserver 监听地址显式改为所有网卡（与 web profile 的 3080 做法一致），端口仍由桌面壳启动参数提供；由用户自行重启桌面端生效。
- 验证：本机 19387 监听地址变为 `0.0.0.0`；服务器侧上游探测返回 200（0.21 秒）、TCP 握手成功；公网入口无凭据仍为 401，认证屏障未受影响。
- 备注：绑定所有网卡后，局域网与 Tailscale 网段可无 Basic Auth 直连 19387（官方 CLI 的 `--host 0.0.0.0` 被刻意禁止，本次经 profile patch 覆盖）；该项改动需重启桌面端才生效。
